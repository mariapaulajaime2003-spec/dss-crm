# Decisiones inteligentes, clientes satisfechos

Sistemas de Soporte a la Decisión (DSS) y CRM en la gestión empresarial.

Recurso educativo digital para la asignatura **Sistemas de Información Gerencial** (Administración de Empresas).

## Contenido

1. Inicio: los datos como herramienta de gestión
2. Sistemas de Soporte a la Decisión (DSS)
3. CRM y gestión de clientes
4. Comparación entre DSS y CRM
5. Caso empresarial (NovaMarket, ficticio) y laboratorio interactivo
6. Conclusiones, bibliografía y créditos

## Características

- HTML5, CSS3 y JavaScript puro, en un solo archivo (`index.html`)
- Sin servidor, base de datos, cuentas ni claves API
- No recolecta datos personales
- Adaptable a computador, tableta y celular, con modo oscuro
- Navegación por teclado

## Publicar gratis en GitHub Pages

1. Crea un repositorio público en https://github.com/new (por ejemplo `dss-crm`).
2. Sube `index.html` y `README.md`.
3. Ve a **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En uno o dos minutos estará en `https://TU-USUARIO.github.io/dss-crm/`.

## Verificar el acceso público

Abre el enlace en una ventana privada del navegador y desde otro dispositivo sin sesión iniciada.

## Nota académica

NovaMarket y sus cifras son ficticios y se presentan como ejemplos ilustrativos. La bibliografía debe verificarse (edición, año y editorial) en la biblioteca institucional antes de la entrega. El recurso se elaboró con apoyo de inteligencia artificial y debe ser revisado por el estudiante y el docente.
